## Contexto y Justificación
Antes de definir el "qué", se debe tener absoluta claridad sobre el "por qué".

### Contexto
Que producto estámos validando, ideal tener información sobre el producto, mercado, competidor y usuario.
1. Datos sobre el producto (funcionalidades, flujos, etc)
2. Datos sobre el mercado (tendencias, segmentos, etc)
3. Datos sobre el competidor (productos, flujos, etc)
4. Datos sobre el usuario (segmentos, comportamientos, etc)

### Justificación
1.  **¿Por qué se va a realizar esta investigación?:** Explicación del origen (ej. caída en conversión, nueva funcionalidad, validación de supuesto).
2.  **¿Qué quiere saber negocio con esta investigación?:** Pregunta de negocio central que se busca resolver.
3.  **¿A qué OKR del equipo le apunta esta investigación?:** Vinculación directa con las metas estratégicas del trimestre.
