# Proceso de Investigación - Hoja: Protocolos

## Gestión de Plantillas
Esta hoja centraliza el acceso a las herramientas de recolección de datos. Para mantener la integridad del proceso, se debe descargar una copia de la plantilla necesaria y posteriormente integrarla a este libro de trabajo siguiendo las instrucciones de la hoja Intro.

### Instrucciones de Uso
* **Descarga:** Utiliza los enlaces proporcionados para obtener la última versión de cada protocolo.
* **Vinculación:** En caso de no usar una pestaña de Excel integrada, es obligatorio asegurar que el protocolo externo esté en el repositorio y dejar el enlace directo en esta sección.
