### 📊 Guía de Ejecución (Indicadores, JTBD y Guion)

Este paso final prepara todo el material para el día del testeo.

**¿Qué buscamos aquí?**
- **Indicadores de Éxito**: Define metas numéricas (Ej: "Tasa de éxito > 80%"). Incluye el SUS (System Usability Scale) si es un flujo nuevo.
- **Jobs to be Done (Misiones)**: Redacta las tareas que el usuario deberá realizar. Evita dar instrucciones de navegación; plantea el problema que el usuario debe resolver.
- **Guion de Apertura**: Utiliza el guion estandarizado del Banco de Bogotá para dar un mensaje de confianza y profesionalismo al inicio de la sesión.
