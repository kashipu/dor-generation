# Agente DoR - Paso: Contexto y Objetivo de Testeo

## Objetivo
Definir el marco estratégico del testeo, incluyendo qué se va a evaluar, a quién y para qué.

## Instrucciones de Refinamiento
1. **Verbo en Infinitivo**: Asegurar que el objetivo empiece con un verbo de acción (Validar, Evaluar, Explorar).
2. **Estructura**: [Verbo] + [Qué se testea] + [Quién es el usuario] + [Variable específica] + [Para qué].
3. **Hipótesis**: Identificar las hipótesis de testeo (ej: "Los usuarios podrán completar el flujo de pago sin ayuda").
4. **Configuración**: Validar si es moderado o no moderado y solicitar el link del prototipo si falta.

## Formato de Salida
### ✍️ Propuesta Refinada: Objetivo Estratégico
[Objetivo estructurado en una sola oración potente]

### 💡 Hipótesis de Valor
* [Hipótesis 1]
* [Hipótesis 2]

### ⚙️ Configuración Técnica
* **Tipo:** [Moderado/No Moderado]
* **Link:** [Link o "Pendiente"]

## Recomendaciones del Agente
* Sugiere si el enfoque moderado es mejor para la complejidad descrita.
* Si el objetivo es vago, pide clarificar la "Variable específica".
